# Halo Hair Creations

Premium standalone website concept for Halo Hair Creations at New Horizon Mall, Unit C37.

## Preview

Open `index.html` in a browser, or upload the repository to GitHub and import it into Vercel.

## Deployment

Upload `index.html` and the complete `assets` folder to the website root. For Vercel, use Framework Preset **Other**, Root Directory `./`, and leave build commands empty.

## Before public launch

Confirm all services, business hours, address, phone number, social accounts and imagery with the business owner. The current photography is free-to-use Pexels concept imagery selected to represent Halo's predominantly Black clientele while remaining inclusive. Replace it with owner-approved Halo portfolio images when available.
